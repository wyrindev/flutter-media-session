# Security Policy

## Supported Versions

Security updates are actively provided for the current major version of `flutter_media_session`.

| Version | Supported          |
| :------ | :----------------- |
| 3.x.x   | :white_check_mark: |
| 2.x.x   | :x:                |
| 1.x.x   | :x:                |

---

## Reporting a Vulnerability

Security is taken seriously. If you discover a security vulnerability, please report it privately rather than creating a public issue.

### Preferred Method: GitHub Private Vulnerability Reporting
You can report security vulnerabilities privately via GitHub:
1. Navigate to the repository's [Security Advisory Tab](https://github.com/wyrindev/flutter-media-session/security/advisories).
2. Click **"Report a vulnerability"**.
3. Fill out the advisory form with details on how to reproduce the issue.

### Alternative Method: Email
If GitHub Private Vulnerability Reporting is unavailable, you can contact the maintainer directly via email:
- **`wyrindev@proton.me`** or **`wyrindev@gmail.com`**

Please include:
- A description of the vulnerability and its potential impact.
- Affected platforms.
- Steps to reproduce or a minimal proof-of-concept example.
- Any suggested mitigations.

### Response
- **Response Time**: Receipt will be acknowledged within 48 hours.
- **Credit**: Reporters following responsible disclosure will be credited in the release notes and security advisory (unless anonymity is requested).
- **Public Disclosure**: Please allow reasonable time for a patch release before public disclosure.
